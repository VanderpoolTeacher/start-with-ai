Install it

git clone https://github.com/VanderpoolTeacher/start-with-ai.git
mkdir -p ~/.claude/skills
cp -r start-with-ai/skills/* ~/.claude/skills/

That's the whole install. A skill is picked up as soon as its folder exists — no restart, no registration. Start Claude Code and say "good morning" and the matching skill fires.

The four skills

  • business-cards A photo becomes a contact, a task, an unsent draft, an archived original — and an honest list of what it couldn't read.
  • morning-plan Weather, today's schedule, the travel gaps and collisions hiding in it, then a plan you approve before anything is written.
  • daily-briefing Every inbox you have, read into one answer: what needs you today. Never writes anything.
  • email-triage Who is genuinely waiting on you, and drafts you press send on yourself.

Before they work

Every skill ships as a template. Personal values are double-braced and need replacing:

grep -rn "{{" ~/.claude/skills/

At minimum set {{USER_NAME}} and {{HOME_CITY}} — those two make the morning skill useful on day one. A skill with placeholders left in still runs; it just asks you the questions the placeholder was meant to answer.

The one rule worth stealing

Reads are free. Writes ask first. Sends never happen.

Every skill here is read-only until it has shown you what it plans to do. That's not a limitation — it's why these are usable on a real inbox instead of a test account.
